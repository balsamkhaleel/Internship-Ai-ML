\# Technical Report — Cardiac Patient Monitoring System\## Project OverviewThe \*\*Cardiac Patient Monitoring System\*\* is an end-to-end AI/ML project designed to estimate cardiovascular disease risk using demographic, clinical, and lifestyle patient data.The project covers the full machine learning lifecycle:\*\*Data Preparation → EDA → Feature Engineering → Modeling → Optimization → Evaluation → Explainability → Serialization → Experiment Tracking → Application Development → Deployment\*\*\---\## Problem StatementCardiovascular disease is a major health challenge, and early risk estimation can support timely medical evaluation.The goal of this project is to build a machine learning system that estimates cardiovascular risk based on patient information.The system is intended for educational and analytical purposes and is not a medical diagnostic tool.\---\## DatasetThe project uses the \*\*Cardiovascular Disease Dataset\*\*, originally containing approximately \*\*70,000 patient records\*\*.Main features include:\- Age\- Gender\- Height\- Weight\- Systolic blood pressure\- Diastolic blood pressure\- Cholesterol\- Glucose\- Smoking\- Alcohol intake\- Physical activityThe target variable is:```textcardio
