\# Model Card — Cardiac Patient Monitoring System\## Model OverviewThe final model is a tuned Neural Network developed to estimate cardiovascular disease risk using demographic, clinical, and lifestyle patient information.The model is part of the \*\*Cardiac Patient Monitoring System\*\* and is integrated into a deployed Streamlit application.\---\## Intended UseThe model is designed for:\- Educational purposes\- Cardiovascular risk estimation\- Demonstrating an end-to-end AI/ML workflow> The model is not intended to provide a medical diagnosis or replace professional medical evaluation.\---\## Model Architecture\- Model Type: Neural Network\- Input Features: 14\- Architecture: `64-32-1`\- Learning Rate: `0.0001`\- Dropout: `0.0`\- Batch Size: `64`\- Classification Threshold: `0.42`\- Random Seed: `42`\---\## Input FeaturesThe model uses the following 14 features:\- `gender`\- `height`\- `weight`\- `ap\\\_hi`\- `ap\\\_lo`\- `cholesterol`\- `gluc`\- `smoke`\- `alco`\- `active`\- `age\\\_years`\- `bmi`\- `pulse\\\_pressure`\- `map`\---\## Final Evaluation| Metric | Result ||---|---:|| Accuracy | `0.7187` || Precision | `0.6931` || Recall | `0.7744` || F1-score | `0.7315` |\---\## ExplainabilitySHAP was used to analyze feature influence on model predictions.Important features included:\- Systolic Blood Pressure (`ap\\\_hi`)\- Age (`age\\\_years`)\- Pulse Pressure\- Mean Arterial Pressure (`map`)\- Cholesterol\---\## Model ArtifactsThe production workflow uses:\- `final\\\_neural\\\_network.keras`\- `standard\\\_scaler.joblib`\- `best\\\_threshold.txt`These artifacts preserve the trained model, fitted scaler, and selected classification threshold.\---\## Limitations\- The model was trained using a public cardiovascular dataset.\- The dataset may not represent every population or clinical environment.\- Model predictions depend on the quality and accuracy of the input information.\- External clinical validation has not been performed.\- Performance may change when the model is applied to different populations.\---\## DeploymentThe final model is integrated into a Streamlit application and deployed publicly
