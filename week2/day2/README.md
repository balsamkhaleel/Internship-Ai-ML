## Key Concepts



* Probability basics: favorable outcomes over total possible outcomes

* Core probability rules: complement, addition, and multiplication

* Conditional probability: (P(A|B))

* Bayes' theorem: prior, likelihood, and posterior

* Common probability distributions:



 * Normal (Gaussian) distribution

 * Binomial distribution

 * Uniform distribution

* Probability simulation and random sampling

* Relationship between probability and Machine Learning



## Tasks

## Key Takeaway



Probability is a fundamental concept in Machine Learning because many ML models produce probabilistic predictions. Conditional probability and Bayes' theorem provide the mathematical foundation for reasoning from evidence and updating predictions. Probability distributions help us understand how data behaves, with the normal, binomial, and uniform distributions being common examples. Through simulation, theoretical probability concepts can be demonstrated and verified using real code.
