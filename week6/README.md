# 📅 Week 6 — Deep Learning Fundamentals



## 📖 Overview



BinX Tech — AI \& Machine Learning Internship Program



This folder contains my Week 6 work: fundamental concepts and practical applications of deep learning. The week focuses on neural network architecture, neurons, layers, weights, biases, activation functions, and training neural networks.



The work is applied to the Cardiovascular Disease dataset, starting with data preparation, exploratory data analysis, and a baseline model before building neural network models.



## 📚 Days



* ✅ **Day 1 — Sprint 1 Planning \& Baseline Model**
* ✅ **Day 2 — Activations, Forward Propagation \& Loss**
* ✅ **Day 3 — Backpropagation, Gradient Descent \& Optimizers**
* ✅ **Day 4 — Building \& Training a Neural Network with Keras**
* ✅ **Day 5 — Tuning, Evaluation \& Sprint Review**



## 🛠️ Technologies



Python, Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook, Git, GitHub
